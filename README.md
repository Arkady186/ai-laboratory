# ИИ‑Лаборатория — Учим думать. Учим создавать.

Современный одностраничный сайт образовательной программы по искусственному интеллекту для детей **7–10, 11–13 и 14–16 лет**.

## 🚀 Как запустить

Ничего устанавливать не нужно — сайт полностью статический (HTML + CSS + JS):

1. Скачайте/клонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/ai-laboratory.git
   ```
2. Откройте файл `index.html` двойным кликом в любом браузере.

Или запустите через локальный сервер (по желанию):

```bash
# Python 3
python -m http.server 8080

# или Node.js
npx serve .
```

Затем откройте http://localhost:8080

## 📁 Структура проекта

```
├── index.html      # главная страница
├── css/
│   └── style.css   # стили
└── js/
    └── script.js   # интерактив (вкладки, аккордеоны, анимации)
```

## ✨ Возможности

- 3 возрастные группы: 7–10, 11–13, 14–16 лет
- Вкладки с программами и модулями-аккордеонами (9 модулей, 72 занятия)
- Анимации при скролле, счётчики, прелоадер
- Галерея фотографий
- Форма записи на занятие
- Полная адаптивность: мобильные, планшеты, десктоп
- Тёмная современная тема с градиентами
